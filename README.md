# 회귀한 마왕은 나의 타워를 기억한다

> NAN 2026 사전 과제. 마왕이 내 타워를 읽고, 선언하고, 그대로 온다.
> 격퇴해도 — 놈은 기억을 갖고 회귀한다.

**▶ 바로 플레이: https://euijkim.github.io/doppel-game/game/td/**
설치·계정·API 키 없음. 링크를 열면 바로 돈다.

## 어떻게 노는가

타워 디펜스다. 타워 4종(화살·대포·마법·저격)을 짓고 10웨이브를 막는다. 다른 점은 하나 — **웨이브가 테이블이 아니라 AI다.**

매 웨이브 직전, 마왕 디렉터가:

1. **읽는다** — 붉은 스캔이 내 타워를 훑고, 가장 투자가 많은 타워에 락온이 찍힌다 (강화 투자까지 읽는다)
2. **선언한다** — *"화살탑이 3개라… 잔딜은 철갑이 먹는다."*
3. **그대로 실행한다** — 선언한 유닛이 실제로 주력으로 온다. 거짓 선언 0건 (자동 계측으로 보증)

웨이브 10에는 마왕이 직접 강림한다 — 본체 비용도 예산에서 차감되고(치트 없음), 이번 판에 내 방어를 뚫었던 유닛이 앞장선다.

그리고 죽어도 끝이 아니다. 마왕은 localStorage로 **회귀**한다: *"회귀 3번째다. 넌 2판 중 2판을 화살탑으로 시작했지. 이번에도 그럴 건가?"* 나를 격퇴할수록 다음 생의 예산이 오른다 — 이기는 유저에게만 걸리는 군비경쟁.

**조작**: 하단에서 타워 선택 → 빈 자리 클릭 설치. 타입 미선택 상태에서 내 타워 클릭 = 강화(Lv5까지 — 커지고 강해진다, 강화 비용은 타워 위 ⬆ 배지). ⛏ 판매 70% 환불, ⏩ 배속, 🔊 음소거.

## 게임 속 AI

런타임 AI는 LLM이 아니라 **로컬 디렉터**(결정론적 분석 + 학습 통계)다. 상성표 기반 카운터 편성, 예산 하드캡(마왕도 치트 불가), 선언→실행 무결성, 회귀 기억. 설계 근거와 "왜 LLM을 안 썼는가"는 [AI 활용 기술 문서](docs/04-ai-doc-draft.md)에.

## 과정 아카이브 — 이 레포에는 게임이 4개 있다

제출작은 `game/td/` 하나다. 나머지 셋은 **버린 게 아니라 밟고 올라온 계단**이고, 전부 플레이 가능한 상태로 남겨뒀다.

| # | 게임 | 무엇을 배웠나 |
|---|---|---|
| 1 | [도플: 한 장 더](https://euijkim.github.io/doppel-game/game/) (카드) | 분신이 내 GO/STOP을 배우는 구조는 섰지만, 코어 룰의 도파민이 부족했다 |
| 2 | [도플: 결투](https://euijkim.github.io/doppel-game/game/duel/) (반응 대전) | 손맛은 잡았지만 AI 개입이 30~60초 시연에서 안 보였다 |
| 3 | [도플: 아레나](https://euijkim.github.io/doppel-game/game/arena/) (오토배틀러) | 관전+자동화 방향은 맞았지만 패턴 다양성이 부족했다 |
| 4 | **회귀한 마왕** (TD) | 위 셋의 답: AI가 매 웨이브 보이게 개입하고, 회귀 기억이 다시 부른다 |

의사결정 과정(직접 플레이 → 판정 → 피벗)은 커밋 로그에 전부 남아 있다.

## 기술

순수 HTML/CSS/JS. 프레임워크 0, 빌드 0, 외부 API 0, 에셋 파일 0(사운드는 WebAudio 실시간 합성). 저장은 localStorage. 1인 개발 (기획 + Claude 협업 — 과정은 커밋 로그에).
