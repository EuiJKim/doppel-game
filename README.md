# 회귀한 마왕은 나의 타워를 기억한다

> NAN 2026 사전 과제. 마왕이 내 타워를 읽고, 선언하고, 그대로 온다.
> 격퇴해도 — 놈은 기억을 갖고 회귀한다.

**▶ 바로 플레이: https://euijkim.github.io/doppel-game/game/td/**
설치·계정·API 키 없음. 링크를 열면 바로 돈다.

**심사자 모드**: [?demo 링크](https://euijkim.github.io/doppel-game/game/td/?demo) — 회귀 3회차의 기억이 시딩된 상태로 시작 (첫 판부터 개전 인사·회귀록·군비경쟁 확인 가능. 화면에 배지로 표기되고, 저장되지 않는다). 본인의 회귀는 파라미터 없이 처음부터.

## 어떻게 노는가

타워 디펜스다. 타워 4종(화살·대포·마법·저격)을 짓고 10웨이브를 막는다. 다른 점은 하나 — **웨이브가 테이블이 아니라 AI다.**

매 웨이브 직전, 마왕 디렉터가:

1. **읽는다** — 붉은 스캔이 내 타워를 훑고, 가장 투자가 많은 타워에 락온이 찍힌다 (강화 투자까지 읽는다)
2. **선언한다** — *"화살탑이 3개라… 잔딜은 철갑이 먹는다."*
3. **그대로 실행한다** — 선언한 유닛이 실제로 주력으로 온다. 거짓 선언 0건 (자동 계측으로 보증)

웨이브 10에는 마왕이 직접 강림한다 — 본체 비용도 예산에서 차감되고(치트 없음), 이번 판에 내 방어를 뚫었던 유닛이 앞장선다.

그리고 죽어도 끝이 아니다. 마왕은 localStorage로 **회귀**한다: *"회귀 3번째다. 넌 2판 중 2판을 화살탑으로 시작했지. 이번에도 그럴 건가?"* 나를 격퇴할수록 다음 생의 예산이 오른다 — 이기는 유저에게만 걸리는 군비경쟁.

**조작**: 하단에서 타워 선택 → 빈 자리 클릭 설치. **내 타워 클릭 = 강화**(Lv5까지 — 커지고 강해진다, 비용은 타워 위 ⬆ 배지). ⛏ 판매 70% 환불, ⏩ 배속, 🔊 음소거.

## 게임 속 AI

런타임 AI는 LLM이 아니라 **로컬 디렉터**(결정론적 분석 + 학습 통계)다. 상성표 기반 카운터 편성, 예산 하드캡(마왕도 치트 불가), 선언→실행 무결성, 회귀 기억. 설계 근거와 "왜 LLM을 안 썼는가"는 [AI 활용 기술 문서](docs/04-ai-doc-draft.md)에.

## 번외 — 섯다 온라인 (친구와 방 코드로)

**▶ https://euijkim.github.io/doppel-game/game/seotda/**

서버·계정 없이 친구 6명까지 붙는 섯다. 방장이 "방 만들기"를 누르면 5자리 코드가 나오고, 친구는 코드(또는 초대 링크)로 들어온다 — 게임 중에도 언제든 (다음 판부터 참가). 방장 브라우저가 판을 돌리고(호스트 권위), 나머지는 WebRTC로 직접 연결된다. 각자에게는 **자기 시점의 상태만** 전송되므로 남의 패는 네트워크로도 새지 않는다.

- 모드 3종: **2장 섯다** · **3장 섯다**(3장 중 1장을 골라 상대에게 공개, 나머지 2장으로 승부) · **홀덤 섯다**(개인 2장 + 가운데 공유 1장, 베팅 후 공개 → 3장 중 2장 선택). 방장이 언제든 전환(다음 판부터)
- 캐릭터 4종(블랙 강아지·홍어먹는 순지형·일베하는 강현이·헛둘우영(움직이는 아바타, 영상에서 추출한 애니메이션 WebP)) 선택, 자리 아바타 + 상황별 말풍선. 합성 BGM(긴장감 루프, 내 차례엔 심장박동)과 좋은 패 팡파르, 쇼다운 순차 공개. 카드 딜 비행, 행동 팝업(콜!·하프 300!), 턴 넘어올 때 잠깐 뜸, 내 패 리액션(대박!!!·어이구 좋다~·…망했다), 승리 연출(딴 돈 카운트업·동전 비·연승), 판돈·내 돈 카운트업, 마지막 5초 틱
- 판돈(앤티) 100원 고정 · 시작금은 방장이 설정(기본 10,000원, 1,000~10,000,000원) · 돈을 다 잃으면 언제든 시작금으로 재참가
- 족보: 광땡·땡·알리~세륙·끗, 특수족보(땡잡이 = 3·7 어떤 조합이든, 암행어사, 49파토 = 4·9 어떤 조합이든 무조건 재경기. 설정에서 OFF 가능)
- 베팅: 삥·따당·쿼터·하프·콜·체크·다이, 올인 사이드팟, 구사 재경기(팟 이월), 턴 타이머
- **쪼기 5종**: 내 카드는 뒤집혀 오고 위로·옆으로·모서리·뒤집기·살살(꾹 누르기) 중 골라 직접 연다
- 화투 앞면은 실사 이미지(`cards/*.png`, 20장), 뒷면·폴백 도안은 SVG. 타짜 풍 도박장 배경(갓등·연기, CSS), 테이블 위 칩 더미(각자 앞·판돈)·칩 날아가기·족보 배너·광땡 컨페티 이펙트
- **봇(컴퓨터 플레이어)**: 친구가 모자라면 방장이 🤖 봇을 넣는다. 패 강도·판돈 대비 콜 금액·성격(공격성/블러핑)으로 베팅하고, 3장·홀덤에선 최선 2장 선택, 진 사람이면 다음 게임 선택, 파산하면 재참가, 이기고 지면 채팅으로 한마디
- **방장 이전**: 방장이 튕기면 자리 순서로 다음 사람이 같은 방 코드로 방을 이어받고 나머지는 자동 재접속(진행 중이던 판은 무효·환급). 자리 비움, ⏱ +15초(판마다 1회), 📊 전적(판수·승·순손익·최고 족보·연승·최근 판), 퀵 채팅(말풍선)
- 쇼다운 무대: 테이블이 어두워지고 가운데 무대에 한 사람씩 올라와 큰 카드를 쪼듯이 천천히 열고(약 1초/장), 족보 도장, 앞사람을 이기면 "역전!", 마지막 승자는 심장박동·상승음 뒤 슬로모션 공개. 건너뛰기 버튼. **진 사람(가장 많이 잃은 사람)이 다음 게임(2장/3장/홀덤)을 고른다**(설정에서 끌 수 있음). 판 시작 때 덱 섞기 → 딜러 다음 사람부터 한 장씩 돌아가며 딜
- 코드: `game/seotda/` — `rules.js`(족보) · `engine.js`(판 진행·모드) · `cards.js`(카드 렌더) · `net.js`(P2P) · `app.js`(UI). 로직 테스트는 `node game/seotda/test.js`
- 자체 시그널링 서버를 쓰려면 `?peer=host:port` (예: `npx peer --port 9000 --path /`)

## 과정 아카이브 — 이 레포에는 게임이 4개 있다

제출작은 `game/td/` 하나다. 나머지 셋은 **버린 게 아니라 밟고 올라온 계단**이고, 전부 플레이 가능한 상태로 남겨뒀다.

| # | 게임 | 무엇을 배웠나 |
|---|---|---|
| 1 | [도플: 한 장 더](https://euijkim.github.io/doppel-game/game/) (카드) | 분신이 내 GO/STOP을 배우는 구조는 섰지만, 코어 룰의 도파민이 부족했다 |
| 2 | [도플: 결투](https://euijkim.github.io/doppel-game/game/duel/) (반응 대전) | 손맛은 잡았지만 AI 개입이 30~60초 시연에서 안 보였다 |
| 3 | [도플: 아레나](https://euijkim.github.io/doppel-game/game/arena/) (오토배틀러) | 관전+자동화 방향은 맞았지만 패턴 다양성이 부족했다 |
| 4 | **회귀한 마왕** (TD) | 위 셋의 답: AI가 매 웨이브 보이게 개입하고, 회귀 기억이 다시 부른다 |

의사결정 과정(직접 플레이 → 판정 → 피벗)은 커밋 로그에 전부 남아 있다.

## 기술

순수 HTML/CSS/JS. 프레임워크 0, 빌드 0, 외부 API 0, 에셋 파일 0(사운드는 WebAudio 실시간 합성). 저장은 localStorage. 1인 개발 (기획 + Claude 협업 — 과정은 커밋 로그에).
