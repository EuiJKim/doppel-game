# NHN 리서치 — 컨셉 선정 근거 (2026-07-21)

목적: 컨셉 채점표의 "설명 가능성" 항목에 쓸 근거. "왜 이 게임을 NHN에 내는가"에 답하기 위함.

## 1. 주최 측이 밝힌 취지 (직접 인용)

- 김상호 NHN 게임사업부문 대표: **"게임에서 AI를 활용해 새로운 경험을 제안하고 이를 실제 결과물로 구현할 수 있는 게임 특화 해커톤"** — "새로운 경험 제안"+"실제 구현"이 한 쌍 (경향게임스 보도)
- 대회명 'Next AI Network' = **"AI 기반의 새로운 게임 개발 생태계 구축"** 의미 (ZDNet)
- 문체부·한국콘텐츠진흥원 후원, 채용 연계형. 본선장 = 판교 사옥 '플레이뮤지엄'
- 사이트 슬로건: "AI를 활용하는 사람은 많다 → **AI의 다음 단계를 설계할 디렉터**"

→ 종합: "AI로 게임을 만들었다"(제작 도구)가 아니라 **"AI로 어떤 새로운 플레이 경험을 제안했는가"**를 묻고 있음. 루브릭의 해석 B 가설이 보도자료로 재확인됨.

## 2. NHN의 게임 AI 이력 — 이 회사에게 게임×AI는 새 얘기가 아니다

- **'한돌'(HanDol)**: 한게임 바둑 20년 기보 데이터로 자체 개발한 바둑 AI. **2019년 이세돌 은퇴 대국 상대(3전 2승)** — 알파고 다음으로 이세돌과 싸운 AI가 NHN 것 (한경 2019-12)
- 한돌은 현재도 활용 중: 2026-07 한중 청소년 바둑 교류에서 '한돌 챌린지'·'한돌 레벨테스트'(기력 맞춤 단계) 제공 (뉴스핌 2026-07-23)
- → **NHN의 게임 AI 원형 = "게임 데이터로 학습해, 플레이어 상대가 되고, 실력에 맞춰주는 AI"**. 심사자(Game AI 조직)의 자부심 지점일 가능성 높음

## 3. NHN의 AI 전환(AX) 현황

- **Claude 전사 도입** — AI 에이전트로 사내 AX 가속 (청년일보). 사내 AI 플랫폼 'Playground' 한국·일본 오픈, 'AI 스쿨' 교육, 'AI 기술 협의체' 운영
- 사내 해커톤 'AI 스프린톤' 이미 개최 — NAN은 그 외부 확장판 격
- → 심사자들은 AI 도구 사용 자체에 익숙함. "Claude로 만들었어요"는 전혀 새롭지 않음. **어떻게 부렸는지의 설계**가 변별점

## 4. NHN 게임사업 컨텍스트 (2026)

- 본진: **한게임 웹보드**(고스톱·포커, 1999~) — 안정 수익원. 소셜카지노 중심 구조에서 **탈피·확장 중**
- 확장: 미드코어·서브컬처로 신작 8종 추진(대부분 자체 개발), '다키스트 데이즈'(포스트아포칼립스 오픈월드 슈팅 RPG) 등 — 게임 DNA 재가동 서사 (디일렉·디지털데일리)
- → 회사의 갈증: "웹보드 회사"를 넘는 **새로운 게임 경험**. 해커톤 취지 문구("새로운 경험 제안")와 일치

## 5. 컨셉 방향 시사점 (채점표와 연결)

1. **해석 B 확정**: 런타임 AI가 게임 메커니즘의 심장인 컨셉 (한돌 계보 — AI가 상대/파트너/심판이 되는 놀이)
2. **NHN 맥락 연결 고리 후보**: ①웹보드의 본질 = "사람 vs 사람 심리전" → AI가 끼어들면? ②한돌의 "실력 맞춤" 전통 → 적응형 난이도/상대 ③"새 경험 제안" → 기존 장르 스킨이 아닌 AI-네이티브 규칙
3. **경계**: 유료 API 본인 부담 + 심사자가 즉시 실행 가능해야 함 → API 키 없이도 돌아가는 구조(로컬 모델·캐시·규칙 폴백) 설계 필요. 이건 기술 리스크이자 차별화 기회
4. 게임 개발 무경험 방어 논리 재료: "디렉터를 찾는다"는 대회 + 기획 이력 + AX 해커톤 본선 이력(AI를 시스템으로 부린 증거)
