# 「회귀한 마왕은 나의 타워를 기억한다」 설계 — 최종 확정판

2026-08-03 확정 (마지막 피벗 — 마감 8/10, D-7). 플레이어 = 타워 짓는 방어자(홈그라운드), AI = **회귀하는 마왕**: 매 웨이브 내 타워 조합을 읽고 예산 안에서 카운터 웨이브를 편성하며, **먼저 선언하고 실행한다**. 죽어도 회귀하여 내 빌드 버릇을 기억하고 돌아온다.

핵심 결정: **마왕 디렉터는 로컬(결정론적 분석 + 학습 통계)** — API 0·비용 0·심사자 5초 실행 전략 유지. LLM 디렉터는 기술문서 "확장 방향" 챕터로. (한돌 계보 서사도 유지)

## 1. 타워 4종 (플레이어)

| 타워 | 비용 | 특성 | 강함 | 약함 |
|---|---|---|---|---|
| 화살탑 | 30 | 단일·빠른 연사·중사거리 | 비무장 단일 | **철갑**(경직 피해 흡수)·물량 |
| 대포탑 | 45 | 스플래시·느린 발사 | **쥐떼**(물량) | 빠른 단일·탱커 |
| 마법탑 | 40 | 범위 감속 + 방어 무시 소딜 | **철갑·질풍**(감속) | 순수 딜 부족·**망령**(감속 면역) |
| 저격탑 | 55 | 초장거리·한방·긴 재장전 | **오우거**(탱커) | **쥐떼**(오버킬 낭비) |

## 2. 유닛 6종 (마왕의 카탈로그, 예산제)

| 유닛 | 예산 | 특성 | 카운터하는 것 | 당하는 것 |
|---|---|---|---|---|
| 고블린 | 8 | 표준 | — (기준선) | 전부 적당히 |
| 쥐떼 | 5 | 초저체력·다수·빠름 | 저격탑(한방 낭비) | 대포탑 |
| 철갑충 | 14 | **방어(타격당 -3)**·느림 | 화살탑(연사 무력화) | 저격탑·마법탑 |
| 질풍 늑대 | 12 | 초고속 | 느린 발사 타워 통과 | 마법탑(감속) |
| 오우거 | 25 | 대체력 탱커 | 소딜 흡수 | 저격탑 |
| 망령 | 18 | **감속 면역** | 마법탑 전략 | 화살탑 |

방어 = 타격당 고정 감산(연사에 강함), 마법 피해는 방어 무시. **사용자 인사이트 반영**: "한방 타워 앞의 물량, 연사 타워 앞의 철갑" — 당황의 순간을 상성표로 시스템화.

## 3. 마왕 디렉터 (로컬 AI) — 선언→실행

매 웨이브 직전:
1. **읽기**: 내 타워 타입 분포 + 배치 밀집도(입구 몰빵/분산)
2. **편성**: 최다 투자 타워의 카운터 유닛을 주력(50~70%), 혼합 유닛으로 나머지. 예산 B(n) = 40 + 22n — **하드캡, 마왕도 치트 불가** (공정한 권한 = 기술문서 챕터)
3. **간격 결정**: 스플래시 많음 → 산개 스폰 / 단일딜 많음 → 밀집 러시
4. **선언**: *"화살탑이 6개라… 철갑충으로 무디게 해주지"*, *"스플래시가 많군. 흩어져서 간다"* — 그리고 실제로 그 웨이브가 나온다. **AI 비가시성 리스크의 생존 장치**
5. **웨이브 후 정직 리포트**: *"네 대포가 내 쥐떼를 갈았군. 인정하지."* (통한 것/막힌 것 통계)

## 4. 회귀 시스템 (localStorage — 죽어도 기억한다)

- 런 종료(클리어=마왕 격퇴 / 패배) 시 요약 저장: 내 주력 타워 성향, 초반 3웨이브 빌드 패턴, 통한 유닛
- 다음 런: 마왕이 회귀 인사로 개전 — *"회귀 3번째다. 넌 항상 입구에 스플래시를 몰더군"* + 1웨이브부터 기억 기반 선편성(완만하게)
- **회귀록** 화면: 마왕이 나에 대해 적은 것 (숫자와 함께 — 정직 원칙 계승)
- 클리어할수록 마왕 예산 계수 증가 = 군비경쟁

## 5. 스코프 (D-7 컷라인)

- 고정 단일 경로 (미로 빌딩 없음 — 카운터 편성이 코어), 스테이지 1개, 웨이브 10개, 목숨 10
- 업그레이드 없음(로드맵), 전생 3단계 → 회귀 기억 누적 1축으로 압축
- 일정: 8/3 룰+엔진 → 8/4 엔진 완성 → 8/5 마왕 디렉터+회귀 → 8/6 밸런스+블라인드 → 8/7 영상+문서 → **8/8 제출**
- 슬립 시 폴백: 아레나/결투 (기존 완성분)
