# 게임 디자인 문서 — 《DOPPEL(도플)》

NAN 2026 사전 과제 · 2026-07-21 확정 · 컨셉 채점 97/100 (judge-rubric.md)
**2026-07-24 코어 교체**: 교실 게임을 쇼다운(숫자 베팅 심리전) → **《한 장 더》(푸시 유어 럭)**로 교체. 사유: 직접 플레이 결과 숫자 비교는 체감 긴장이 약함. 푸시 유어 럭은 매 뽑기가 긴장→해소 구조(도파민)이고, 선택이 GO/STOP 2지선다라 모방이 더 빠르고 노트가 더 선명해짐.

## 0. 한 줄

> **내 플레이를 배워 나 대신 싸우고, 끝내 나와 마주하는 분신 AI** — 내 기보로 만드는 나만의 한돌.

비전 문장(심사·문서·피칭 공통): "NHN이 한게임 20년 기보로 '한돌'을 만들었듯, 이 게임은 플레이어 한 명의 기보로 그 사람의 분신을 만든다."

## 1. 핵심 루프 (4단계)

```
① 배움   나 vs 스파링 AI로 《한 장 더》 → 분신이 관전하며 「노트」 작성
② 파견   분신을 AI 리그에 내보냄(방치) → 나처럼 싸운 전적·약점 리포트 귀환
③ 교정   "분신이 지고 있을 때 너무 일찍 멈춥니다" → 그 상황을 내가 시범 → 분신 갱신
④ 거울전  일치율 임계 도달 시 해금 — 분신 vs 나. 게임의 피날레
```

져도 성립하는 서사: "AI에게 진 게 아니라, 나에게 졌다."

## 2. 교실 — 《한 장 더》 규칙 (모방 학습이 가능하도록 이산 설계)

**게임명(인게임): 한 장 더.** 1:1 푸시 유어 럭, 한 라운드 ~30초.

- 라운드마다 공유 덱: **보석 16장(1점×6, 2점×6, 3점×4) + 폭탄 4장 = 20장**. 남은 폭탄 수는 공개
- 내 턴: **[한 장 더]** 뽑아서 내 더미에 쌓기 — 또는 — **[멈춤]** 더미 점수 확정(뱅킹). 첫 장은 무조건 뽑아야 라운드 참가
- **폭탄을 뽑으면 이번 라운드 내 더미 전부 소멸** 💥 (확정된 점수는 안전)
- 번갈아 턴 진행. 한쪽이 멈추면/터지면 남은 쪽 단독 진행. 덱 소진 시 전원 강제 확정
- 세션: **5라운드 총점 승부**. 선공 교대
- 점수는 점수일 뿐 — 현금성·가챠성 요소 없음 (사행성 배제 원칙, NHN 소셜카지노 탈피 맥락)

이 규칙의 존재 이유: 선택이 **GO/STOP 2지선다**라 모방이 통계적으로 빠르고 안전하며, "언제 멈추는가"에 리스크 성향(겁쟁이/도박꾼, 지고 있을 때의 무리수)이 **숫자로 선명하게 드러남**. 매 뽑기가 긴장→해소의 슬롯 구조라 도파민이 규칙 자체에 내장됨.

### 2-1. 스킬 3종 (2026-07-24 추가)

GO/STOP만으로는 매 턴이 같은 계산이라 중반부 긴장이 평평해진다. **세션당 각 1회**짜리 스킬로 "쓰는 타이밍"이라는 두 번째 결정축을 얹는다. 규칙은 각각 한 줄이라 30초 안에 읽힌다.

| 스킬 | 효과 | 만드는 순간 |
|---|---|---|
| 🛡 방패 | 다음 폭탄 1회 무효 | 방패를 켠 채 달리는 무모함 / 안도의 "막았다" |
| 👁 투시 | 맨 위 카드를 미리 본다 | 폭탄을 보고도 멈출지 말지 — 정보가 있는데도 흔들림 |
| ✕2 배증 | 이번 라운드 확정 점수 2배 (**터지면 무효**) | 선언 후 안전하게 확정할지, 더 쌓을지 — 최대 도파민 |

**핵심: 스킬이 분신의 새로운 학습 대상이다.** 언제 꺼내는지가 그 사람의 성격이므로, 분신은 사용 시점의 상황(점수차·더미·위험)을 기록하고 거울전에서 같은 타이밍에 꺼낸다. 노트도 늘어난다 — *"지고 있고 더미가 어중간할 때 배증을 꺼내는 타입. 5번 봤어요."*

검증: "지고 있을 때 배증" 5회 주입 → 거울 분신이 같은 상황에서 169/200 사용, 이기는 상황에서는 0/200.

스파링 AI 3종도 성격대로 쓴다 — 불도저는 초반에 다 쏟고, 회계사는 위험이 실제로 오를 때만, 여우는 점수판을 보고(지면 배증, 이기면 방패).

## 3. AI 설계 (전부 로컬, API 0)

### 3-1. 스파링 AI (교실 상대) — 아키타입 3종
| 이름 | 성향 | 구현 |
|---|---|---|
| 불도저 | 폭주 — 터질 때까지 간다 | 더미 크기만 보고 GO, 폭탄 비율 무시 |
| 회계사 | 기대값 — 계산이 곧 용기 | EV=(1-p)×평균보석 − p×더미, 양수일 때만 GO |
| 여우 | 상황 — 지면 달리고 이기면 잠금 | 점수차 기반 분기 + 소량 노이즈 |
규칙 기반 + 확률 노이즈. 셋 다 "읽히는 성향"이 있어야 리그 리포트가 서사가 됨.

### 3-2. 분신 엔진 (핵심)
- **상태 버킷**: 더미 점수 3구간(0~3 / 4~7 / 8+) × 점수차 3구간(지는 중 ≤−3 / 비등 / 이기는 중 ≥+3) × 폭탄 위험 2구간(남은 폭탄/남은 카드 0.25 기준) = **18버킷** — 전부 공개 정보만 사용
- 버킷마다 GO/STOP 빈도 + 평균 결정 시간을 기록. 진짜 선택이 있었던 순간만 학습(첫 장 강제 뽑기는 제외)
- 분신 플레이 = 해당 버킷 분포에서 샘플링 + 내 템포를 흉내 낸 "생각하는" 연출
- **표본 부족 버킷은 "아직 못 배운 상황"으로 정직하게 표시** — 채워넣지 않는다 (AX 원칙 계승). 이게 교정 루프(③)의 재료가 됨
- **일치율** = 최근 30선택에서 "분신이 예측한 내 선택 = 실제 내 선택" 비율. 메인 화면 게이지 (예측 가능 버킷이 생긴 뒤부터 측정)

### 3-2b. 백오프 추론 — "왜 분신이 첫 판부터 말할 수 있나" (2026-07-24 추가)

실측 결과 한 라운드에서 기록되는 **진짜 선택은 2~4개뿐**이다(강제 뽑기 제외, 폭탄으로 라운드가 일찍 끝남). 정확한 18버킷 표본만 기다리면 분신은 몇 세션이 지나도 입을 못 연다 — 즉 "나와 마주하는 순간"이 심사자의 3분 밖으로 밀려난다.

해법은 n-gram 백오프와 같은 구조. 좁은 상황부터 넓은 상황으로 물러나며 근거를 찾는다:

| 층 | 근거 범위 | 분신의 말투 |
|---|---|---|
| L0 | 더미×점수차×위험 (이 상황 그대로) | "여기선 무조건 가십니다. 봤어요, 여러 번." |
| L1 | 더미×점수차 | "갈 것 같은데요." |
| L2 | 더미 구간만 | "(더미가 이만할 때 기준) 이건 감인데…" |
| L3 | 전체 성향 | "(평소 성향 기준) 아직 잘 모르지만…" |

**어느 층에서 말하는지 항상 밝힌다.** 넓은 층일수록 "감"이라고 스스로 말한다 — 정직 원칙을 지키면서 조기 발화를 얻는 장치. 영구 노트(단정적 주장)는 여전히 L0 3회 이상에서만 봉인 해제한다.

측정: 백지 분신 기준 **첫 예측 발화 = 두 번째 선택**(자동 플레이 7.2초 시점).

### 3-2c. 조기 대면 장치 (TTW 설계)

"나와 마주함"이 정식 거울전(선택 80회+일치율 65%)까지 밀리는 문제를 두 장치로 해소:

1. **조기 예측 배지** — 내가 버튼을 누르기 *직전*, 분신이 내 선택을 먼저 선언한다. 적중하면 ✓, 빗나가면 ✗. 세션 내 적중률 미니 게이지가 실시간으로 오른다
2. **미니 거울전** — 스파링이라도 **매 세션 마지막 라운드는 분신이 상대석에 앉는다**. "오늘 배운 것만으로" 두고, 못 배운 상황은 어느 층의 기억으로 두는지 말한다. 정식 거울전은 완전체 보스전으로 남긴다

### 3-3. 리그 (방치 라이트)
- 분신 vs 아키타입 3종 × 자동 시뮬(수백 판, 몬테카를로) — 접속 종료 중 "싸운 것으로" 연출
- 산출: 전적, 상대별 승률, 약점 1줄("이기고 있을 때 너무 일찍 잠가서 역전당함"), 하이라이트 텍스트 1판
- 실시간 아님·백엔드 없음: 재접속 시 일괄 시뮬 (localStorage 시각 차 기반)

### 3-4. 거울전 (피날레)
- 해금: 학습 선택 80회 이상 그리고 일치율 65% 이상
- 분신 모델을 상대로 직접 대결. 결과 화면에서 "분신이 안 나(당신의 패턴)" 3줄 공개
- 승패 무관 칭호 부여 — 공유 욕구 장치

## 4. 도파민 설계 (사행성 없이)

0. **읽혔다는 소름**: 내가 누르기 직전 분신이 내 수를 선언하고 적중시킨다 — 이 게임의 가장 강한 감정. 첫 세션 1~2분 안에 발생하도록 설계(3-2b·3-2c)
0b. **얼굴이 또렷해진다**: 분신은 흐릿한 실루엣으로 시작해, 나를 배울수록 초점이 잡히고 눈을 뜨고 끝내 웃는다. 성장을 숫자가 아니라 얼굴로 보여주는 장치 — **한 세션에 선명도 0.00 → 0.38**(블러 5.5→3.4, 눈 0→0.64) 실측
1. **뽑기 연출**: 매 [한 장 더]가 카드 아크 낙하 + 보석 팝 + 폭탄 시 화면 진동·붉은 섬광. 효과음 8종은 WebAudio 실시간 합성(파일 0개)
2. **분신의 노트**: 선택마다 실시간 리액션(특이 상황 ~70%, 평범한 선택도 40%, 3연속 침묵 시 강제 발화). 같은 상황 3회 관찰 시 영구 노트 봉인 해제 — 수집형 도파민 + 학습 가시화
3. **일치율 게이지**: 기르기 진행바. 5% 단위 돌파 연출
4. **칭호**: 분신이 분류한 내 스타일 ("강철 심장", "회계사보다 회계사", "역전의 도박꾼")
5. 연승 스트릭 + "AI 경계 레벨" 연출

## 5. 화면 목록 (6)

1. **홈**: 분신 아바타 + 일치율 게이지 + 노트 최신 3줄 + [배우기/리그/거울전]
2. **대전(교실)**: 카드·팟·행동 버튼 + 우측에 분신 관전석(노트 실시간)
3. **분신의 노트**: 도감형 리스트 (해제된 통찰 + "아직 못 배운 상황" 회색 표시)
4. **리그 리포트**: 전적·약점·하이라이트
5. **거울전**: 대전과 동일 무대, 상대가 "나"
6. **결과·칭호**: 세션 요약 + 공유용 카드 1장

## 6. 기술

- 순수 HTML/CSS/JS (프레임워크 0, 빌드 도구 0) — 링크 클릭 → 5초 내 플레이 (루브릭 논리 25점 직결)
- GitHub Pages 배포, 저장 localStorage, **외부 API 0** (심사자 즉시 실행 보장)
- 모바일 브라우저 대응 (심사자가 폰으로 열 가능성)
- 사운드·아트: AI 생성(출처·도구 문서화) + 최소주의 (완성도 우선)
