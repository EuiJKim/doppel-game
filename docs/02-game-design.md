# 게임 디자인 문서 — 가제 《DOPPEL(도플)》

NAN 2026 사전 과제 · 2026-07-21 확정 · 컨셉 채점 97/100 (judge-rubric.md)

## 0. 한 줄

> **내 플레이를 배워 나 대신 싸우고, 끝내 나와 마주하는 분신 AI** — 내 기보로 만드는 나만의 한돌.

비전 문장(심사·문서·피칭 공통): "NHN이 한게임 20년 기보로 '한돌'을 만들었듯, 이 게임은 플레이어 한 명의 기보로 그 사람의 분신을 만든다."

## 1. 핵심 루프 (4단계)

```
① 배움   나 vs 스파링 AI로 카드 심리전 → 분신이 관전하며 「노트」 작성
② 파견   분신을 AI 리그에 내보냄(방치) → 나처럼 싸운 전적·약점 리포트 귀환
③ 교정   "분신이 큰 팟에서 겁을 냅니다" → 그 상황을 내가 시범 → 분신 갱신
④ 거울전  일치율 임계 도달 시 해금 — 분신 vs 나. 게임의 피날레
```

져도 성립하는 서사: "AI에게 진 게 아니라, 나에게 졌다."

## 2. 교실 — 카드 심리전 규칙 (모방 학습이 가능하도록 이산 설계)

**게임명(인게임): 쇼다운.** 1:1 베팅 심리전, 한 판 30초.

- 덱: 1~10 숫자 카드. 매 라운드 각자 1장 비공개 배분(자기 카드만 봄)
- 시작: 양쪽 앤티 1칩 → 팟 2칩. 선/후공 교대
- 베팅(1라운드):
  - 선공: **체크** 또는 **베팅**(팟의 절반, 올림)
  - 후공: (체크받으면) 체크 또는 베팅 / (베팅받으면) **콜 · 폴드 · 레이즈**(×2, 판당 1회)
  - 레이즈받은 쪽: 콜 또는 폴드
- 쇼다운: 높은 숫자 승, 팟 획득. 동수면 팟 이월
- 세션: 시작 칩 30, 한쪽 파산 또는 20판 종료
- 칩은 점수일 뿐 — 현금성·가챠성 요소 없음 (사행성 배제 원칙, NHN 소셜카지노 탈피 맥락)

이 규칙의 존재 이유: 상태공간이 작고 이산적이라 **모방이 통계적으로 안전**하고, 블러핑 공간(약한 패로 베팅, 강한 패로 함정 체크)이 열려 있어 **성향이 드러남**.

## 3. AI 설계 (전부 로컬, API 0)

### 3-1. 스파링 AI (교실 상대) — 아키타입 3종
| 이름 | 성향 | 구현 |
|---|---|---|
| 불도저 | 공격 — 자주 베팅·레이즈 | 패 강도 임계 낮음 + 블러핑 확률 높음 |
| 회계사 | 보수 — 강할 때만 돈 넣음 | 임계 높음, 블러핑 거의 없음 |
| 여우 | 트리키 — 함정 체크·역블러핑 | 강패 슬로우플레이 확률 부여 |
규칙 기반 + 확률 노이즈. 셋 다 "읽히는 성향"이 있어야 리그 리포트가 서사가 됨.

### 3-2. 분신 엔진 (핵심)
- **상태 버킷**: 내 패 강도 3구간(약 1~4 / 중 5~7 / 강 8~10) × 포지션(선/후) × 직전 상대 행동(없음/체크/베팅·레이즈) = **18버킷**
- 버킷마다 행동 확률 분포(체크/베팅/콜/폴드/레이즈) + 평균 결정 시간을 기록 (라플라스 스무딩)
- 분신 플레이 = 해당 버킷 분포에서 샘플링 + 내 템포를 흉내 낸 "생각하는" 연출
- **표본 부족 버킷은 "아직 못 배운 상황"으로 정직하게 표시** — 채워넣지 않는다 (AX 원칙 계승). 이게 교정 루프(③)의 재료가 됨
- **일치율** = 최근 30판에서 "분신이 예측한 내 행동 = 실제 내 행동" 비율. 메인 화면 게이지

### 3-3. 리그 (방치 라이트)
- 분신 vs 아키타입 3종 × 자동 시뮬(수백 판, 몬테카를로) — 접속 종료 중 "싸운 것으로" 연출
- 산출: 전적, 상대별 승률, 약점 1줄("여우의 함정 체크에 자주 당함"), 하이라이트 텍스트 1판
- 실시간 아님·백엔드 없음: 재접속 시 일괄 시뮬 (localStorage 시각 차 기반)

### 3-4. 거울전 (피날레)
- 해금: 학습 60판 이상 그리고 일치율 65% 이상
- 분신 모델을 상대로 직접 대결. 결과 화면에서 "분신이 안 나(당신의 패턴)" 3줄 공개
- 승패 무관 칭호 부여 — 공유 욕구 장치

## 4. 도파민 설계 (사행성 없이)

1. **쇼다운 연출**: 카드 공개 직전 0.8초 정지 + 사운드 — 긴장→해소
2. **분신의 노트**: 판마다 실시간 한 줄("큰 팟에서는 신중해지시는군요"). 누적되면 「나에 대한 도감」으로 봉인 해제 — 수집형 도파민 + 학습 가시화
3. **일치율 게이지**: 기르기 진행바. 5% 단위 돌파 연출
4. **칭호**: 분신이 분류한 내 스타일 ("냉혈한 블러퍼", "회계사보다 회계사", "도박꾼의 심장")
5. 연승 스트릭 + "AI 경계 레벨" 연출

## 5. 화면 목록 (6)

1. **홈**: 분신 아바타 + 일치율 게이지 + 노트 최신 3줄 + [배우기/리그/거울전]
2. **대전(교실)**: 카드·팟·행동 버튼 + 우측에 분신 관전석(노트 실시간)
3. **분신의 노트**: 도감형 리스트 (해제된 통찰 + "아직 못 배운 상황" 회색 표시)
4. **리그 리포트**: 전적·약점·하이라이트
5. **거울전**: 대전과 동일 무대, 상대가 "나"
6. **결과·칭호**: 세션 요약 + 공유용 카드 1장

## 6. 기술

- 순수 HTML/CSS/JS (프레임워크 0, 빌드 도구 0) — 링크 클릭 → 5초 내 플레이 (루브릭 논리 25점 직결)
- GitHub Pages 배포, 저장 localStorage, **외부 API 0** (심사자 즉시 실행 보장)
- 모바일 브라우저 대응 (심사자가 폰으로 열 가능성)
- 사운드·아트: AI 생성(출처·도구 문서화) + 최소주의 (완성도 우선)

## 7. 3주 일정 (마감 8/10)

| 주차 | 목표 | 완료 정의 |
|---|---|---|
| W1 (7/21~27) | 교실 완결: 쇼다운 규칙 + 스파링 AI 3종 + 행동 로깅 + 기본 UI | 사람 vs AI 20판 세션이 버그 없이 돔 |
| W2 (7/28~8/3) | 분신: 모방 엔진 + 노트 + 일치율 + 거울전 | 60판 학습 후 거울전에서 "나 같다"가 느껴짐 |
| W3 (8/4~8/10) | 리그 라이트 + 도파민 연출 + 폴리시 → **제출물 5종** | judge-panel 2렌즈 90+ 통과 후 제출 |

컷라인(스코프 방어): 밀리면 **리그부터 컷** (거울전이 킬러, 리그는 로드맵 슬라이드로 강등). 노트·거울전·완성도는 사수.

## 8. 제출물 5종 매핑

| 제출물 | 이 게임에서 |
|---|---|
| 빌드+소스 | GitHub Pages (public) + **의미 단위 커밋** (AX 방식 그대로 — 과정이 보이게) |
| 영상 30~60초 | 구성: 노트가 나를 읽는 장면(10s) → 리그 리포트(10s) → **거울전에서 분신에게 지는 장면**(20s) → 칭호(5s) |
| 게임 소개 PDF | 본 문서 요약 + 조작·목표·종료 |
| **AI 활용 기술 문서 PDF** | 2층 구조로 서술: ①게임 속 AI(분신 엔진 설계 — 버킷·스무딩·일치율) ②제작 과정 AI(Claude 활용 프롬프트·역할 분담) — "런타임 AI + 제작 AI" 둘 다 있음이 차별점 |
| 롤 기술서 | 개인 참가 — 생략 |

## 9. 리스크 대장

| 리스크 | 대응 |
|---|---|
| 모방이 "나 같지 않음" | 버킷 단순화(18개)로 통계 안정 + 노트로 근거 노출("이 버릇을 배웠어요") + 일치율로 기대 관리 |
| 20판 학습이 지루함 | 스파링 3종 성향 차이로 변화 + 노트 실시간 해제가 당근 |
| 심사자가 60판을 안 채움 | **심사자 모드**: URL 파라미터로 "사전 학습된 데모 분신" 즉시 체험 (본인 분신은 처음부터) |
| 사행성 오해 | 칩=점수 명시, 환전·구매 없음, 문서에 원칙 기재 |
