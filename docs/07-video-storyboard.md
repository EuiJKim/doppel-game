## 녹화 가이드 (님이 할 일 — 총 2개 파일이면 충분)

**세팅 (한 번만)**
1. 크롬 새 창 → https://euijkim.github.io/doppel-game/game/td/ → **Ctrl+F5**
2. 회귀록 → **기억 지우기** (첫 회차 상태로 — 컷 7의 "회귀 2번째다"가 정확해짐)
3. **F11 전체화면** (주소창·북마크 제거), 알림 끄기, 시스템 볼륨 적당히 (게임 사운드가 녹음돼야 함 — 음소거 🔊 상태 확인)
4. **Win+G** (Xbox Game Bar) → 녹화 (시스템 소리 포함 확인). 해상도는 모니터 기본 그대로

**녹화 1 — 풀런 (약 4~6분, 배속 ×2 권장)**
- 화살탑 2~3개로 시작 (→ 마왕이 "철갑" 선언을 하게 유도됨: 컷 2·3·4 재료)
- 중간에 강화 연타 장면 한 번 (컷 5 재료)
- 웨이브 10 강림까지 완주 → 승리 → 결산 대사까지 녹화 유지
- **승리 후 [다음 회차] 클릭 → 개전 인사 배너가 뜬 뒤 3초 기다렸다가** 녹화 종료 (컷 7 재료)
- 지면? 그대로 다시 — 패배해도 "재도전 (놈은 기억한다)" → 개전 인사는 동일하게 나옴

**녹화 2 — 타이틀 (10초)**
- 새로고침 → 타이틀 화면 2초 → 방어 시작 누르는 장면 (컷 1·8 재료)

## 편집 원칙 (조립 담당 메모)

- 자막: 흰색 + 검은 외곽, 하단 중앙, 켜지고 꺼지는 타이밍은 컷 표 기준. 폰트는 시스템 맑은고딕
- 사운드: 게임 원음 그대로. 페이드인/아웃 0.3초만
- 컷 4의 물량 장면은 배속 ×2 구간을 그대로 써서 밀도 극대화
- 인코딩: 1920×1080(또는 원본 해상도 유지), H.264, 30fps, 유튜브 업로드용
