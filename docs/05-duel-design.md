# 《도플: 결투》 설계 — 죽을수록 나를 아는 검객

2026-07-24 장르 피벗 확정. 카드 푸시유어럭의 구조적 한계(숨긴 정보 0 · 상대 인터랙션 0 = 병렬 솔리테어, 메타가 약한 코어를 못 살림)를 직접 플레이 판정으로 확인 → **"재미 먼저, AI는 그다음"** 순서로 재작. D1 손맛 프로토가 사용자 판정 통과("이게 훨씬 재밌네") 후 D2에서 학습 AI 이식.

## 0. 한 줄

> **당신의 그림자가 당신을 배워, 당신을 베러 온다.** 이기는 방법은 하나 — 당신 자신을 배신하는 것.

적의 정체 = **그림자** (7/24 리브랜딩): "분신(도플)" 서사와 게임 실체를 봉합하는 이름. 그림자는 알수록 눈빛이 밝아지고 보라 윤곽이 짙어진다 — 성장의 시각화(카드 버전 얼굴 선명도 장치의 계승).

비전 문장(심사·문서 공통): "이 게임의 난이도 곡선은 당신 자신이다. 당신이 예측 가능해지는 만큼 게임이 어려워진다."

## 1. 코어 룰 (AI 없이도 재밌어야 하는 층 — D1에서 검증됨)

- 1:1 검투. 적이 공격을 **예고**: 상단베기(금) / 하단베기(적) / 찌르기(보라)
- 응수 3버튼: ⚔쳐내기 / ⤴점프 / ↪흘리기 (키보드 A·S·D). 정답 응수 → **빈틈** → 아무 버튼 = 반격
- **완벽 판정**: 예고 종료 직전 170ms 안에 응수 = 2딜 — 늦출수록 큰 보상, 긴장의 심장
- 오응수는 커밋되어 그대로 맞는다 (선택의 무게). 빈틈 없는 공격은 막힘
- 결투 승리 → 다음 결투: 예고 850ms에서 8%씩 가속 (min 460ms), 적 HP 성장. 엔드리스, 기록 = 도달 결투

## 2. 학습 AI (D2) — 3가지 무기

놈은 죽지 않고, 새로고침해도 기억한다 (localStorage). 배우는 건 두 가지:

| 관찰 | 학습 | 무기 |
|---|---|---|
| 공격별 적중 이력 | 어떤 공격에 잘 맞는가 | **약점 편중** — 실패율만큼 그 공격 가중 |
| 응수 시점 (t/예고길이, 최근 12회) | 성급한가 / 완벽만 노리는가 | 성급(<55%) → **페인트** / 완벽충(>80%) → **속공**(예고 ×0.62) |

**페인트**: 가짜 예고로 시작 → 도중에 진짜로 전환. 성급하게 응수하면 가짜에 **커밋**되어(클래시가 안 울리는 그 정적이 공포) 진짜 칼에 맞는다 — "낚였다".

**패턴 낚시 (역이용 = 이 게임의 심리전)**: 일부러 성급한 척 응수해 페인트를 유도 → 페인트가 오면 전환을 기다렸다 진짜에 응수 = **간파! (무조건 2딜)**. AI의 학습을 미끼로 쓰는 플레이어 전략이 성립한다. 첫 낚임 때 힌트로 간파를 가르친다.

### 2-1. 학습 가시성 수술 (7/24 블라인드스팟 패스 후)

발견된 구멍: 페인트(성급<55%)·속공(완벽충>80%) 조건에서 **중간 타이밍 플레이어는 착취를 한 번도 못 봄** — 핵심 셀링 포인트가 투명해짐. 수술 3건:

1. **페인트 전환 시점을 고정값이 아니라 "당신의 습관 시점 + 15%p" 뒤에 계산** — 어느 타이밍대든 습관대로 치면 가짜에 커밋된다. 편차가 작을수록(리듬이 일정할수록) 더 자주 건다. 속공은 72% 이후 응수자 전담
2. **조롱으로 착취를 티낸다**: 약점 공격이 적중하면 "거봐, 찌르기." / 페인트 적중 시 "네 리듬은 이미 외웠다."
3. 노트 확장: 리듬 일정형("그 리듬 직후에 칼을 바꾼다"), 버릇 없는 고수에겐 정직하게 "버릇이 안 잡힌다. …제법인데."

커버리지: 성급/일정 → 페인트 · 늦음 → 속공 · 자주 맞음 → 약점 편중+조롱 · 무결점 혼란형 → 인정 대사. **전 유형이 2분 안에 학습을 체감.**

**정직 원칙 (AX→도플 계승)**: 인터미션·사망 화면에서 놈이 배운 것을 **숫자와 함께** 낭독한다 — "찌르기에 10번 중 3번 적중 — 계속 노린다", "응수가 성급하다 (평균 30% 시점) — 페인트 장전". 모르는 건 "아직 배우는 중이다"라고 말한다.
