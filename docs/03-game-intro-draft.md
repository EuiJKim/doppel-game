# 게임 소개 (제출용 PDF 초안) — 《도플 DOPPEL》

> 상태: W2 골격. W3에서 스크린샷·최종 수치 채워 PDF 변환.
> 톤 원칙: 과장 수식어 금지. 짧고 직설. 심사자는 하루에 수십 개를 읽는다 — 첫 문단에서 끝낸다.

## 1. 한 줄

**내 플레이를 배워 나 대신 싸우고, 끝내 나와 마주하는 분신 AI.**
NHN이 한게임 20년 기보로 '한돌'을 만들었듯, 이 게임은 플레이어 한 명의 기보로 그 사람의 분신을 만든다.

## 2. 어떻게 노는가 (30초 설명)

- 인게임 코어는 《한 장 더》: 보석 16장 + 폭탄 4장 덱에서 **[한 장 더]** 뽑거나 **[멈춤]**으로 확정. 폭탄이면 이번 라운드 더미 소멸. 5라운드 총점 승부
- 내가 스파링 AI(불도저·회계사·여우)와 싸우는 동안, **분신이 관전하며 내 선택을 기록**하고 실시간으로 노트를 쓴다 ("지고 있을 때는 폭탄이 보여도 달리는 타입")
- 일치율 65% + 선택 80회를 넘기면 **거울전** 해금 — 나에게 배운 대로 두는 나와 싸운다. 져도 성립하는 서사: "AI에게 진 게 아니라, 나에게 졌다"

## 3. 실행 (심사 안내)

- 링크 클릭 → 5초 내 플레이. 설치·계정·API 키 전부 불필요 (URL: __W3에서 GitHub Pages 주소__)
- **심사자 모드**: `?demo` 파라미터 → 사전 학습된 데모 분신으로 거울전 즉시 체험 (본인 분신은 파라미터 없이 처음부터)
- 모바일 브라우저 대응

## 4. 왜 카드 게임인가 (예상 반문에 먼저 답함)

"웹보드 회사에 또 카드 게임?"이라는 반문을 예상한다. 답은 두 가지다.

1. **카드가 아니라 선택을 배우는 게임이다.** 코어가 GO/STOP 2지선다인 이유는 단 하나 — 사람의 리스크 성향이 통계적으로 가장 빨리, 가장 선명하게 드러나는 구조라서다. 분신 학습의 재료로 설계된 규칙이지, 장르 선택이 아니다.
2. **한게임 DNA 위에 한돌을 이식한 구조다.** 카드의 긴장(한게임)과 데이터로 사람을 배우는 AI(한돌)는 NHN만 가진 두 자산이고, 이 게임은 그 교차점에 있다. 다른 회사에 내면 성립하지 않는 기획이다.

사행성 요소는 없다: 점수는 점수일 뿐, 환전·구매·가챠 없음. 폭탄 확률은 전부 공개 정보라 운이 아니라 판단의 게임이다.

## 5. 화면·조작

(W3에서 스크린샷 6종: 홈 게이지 / 대전+관전석 / 분신의 노트 / 거울전 / 결과·칭호 / 심사자 모드)

- 조작은 버튼 2개가 전부: [한 장 더] / [멈춤]
- 종료 조건: 5라운드 총점. 세션당 3~4분
