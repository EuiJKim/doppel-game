# 게임 소개 (제출용 PDF 초안) — 「회귀한 마왕은 나의 타워를 기억한다」

> 상태: 8/7 TD 기준 전면 재작성. PDF 변환 시 스크린샷 삽입.
> 톤 원칙: 과장 수식어 금지. 짧고 직설. 심사자는 하루에 수십 개를 읽는다 — 첫 문단에서 끝낸다.

## 1. 한 줄

**마왕이 내 타워를 읽고, 선언하고, 그대로 온다. 격퇴해도 기억을 갖고 회귀한다.**
타워 디펜스의 웨이브 테이블을 AI 디렉터로 바꿨다 — 매 웨이브가 내 빌드에 대한 응수다.

## 2. 어떻게 노는가 (30초 설명)

- 타워 4종(화살·대포·마법·저격)을 건설 지점 18곳에 짓고 10웨이브를 막는다. 목숨 10, 강화 Lv5(커지고 강해진다), 판매 70%. 몹은 물결로 쏟아진다
- 매 웨이브 직전 **마왕의 시선**: 붉은 스캔이 내 타워를 훑고 → 최다 투자 타워에 락온 → 선언 배너 → 1.7초 뒤 **선언한 그대로** 침공
- 상성이 코어다: 화살 도배 → 철갑충(방어가 잔딜을 먹는다), 저격 도배 → 철갑 쥐떼(한방이 오버킬 낭비), 마법 도배 → 망령(감속 면역), 대포 도배 → 산개한 질풍 늑대
- 같은 수는 두 번 안 쓴다 — 단, 지난 웨이브에 뚫린 유닛은 *"통했지. 그래서 더 간다"* 선언과 함께 배가
- 웨이브 10에는 **마왕이 직접 강림**한다 — 본체도 예산에서 차감(치트 없음), 이번 판에 내 방어를 뚫었던 유닛이 앞장선다
- 죽거나 이겨도 마왕은 **회귀**한다: *"회귀 3번째다. 넌 2판 중 2판을 화살탑으로 시작했지."* 격퇴할수록 다음 생의 예산이 오른다

## 3. 실행 (심사 안내)

- **https://euijkim.github.io/doppel-game/game/td/** — 링크 클릭 → 5초 내 플레이. 설치·계정·API 키 전부 불필요
- 타이틀의 **[마왕의 회귀록]**: 마왕이 나에 대해 적은 것을 숫자와 함께 낭독 (몇 판 중 몇 판을 어느 타워로 시작했는지, 뭐가 뚫혔는지, 다음 생 예산 계수)
- 데스크톱·모바일 브라우저 대응, 배속 ×2 지원

## 4. 왜 이 게임인가

**TD 고인물이 가장 무서워하는 순간을 AI가 실시간으로 만든다.** 타워 디펜스에서 심장이 내려앉는 순간은 정해져 있다 — 한방 타워를 도배했는데 방어 높고 체력 낮은 물량이 쏟아질 때, 스플래시를 믿었는데 적이 흩어져 올 때. 기존 TD는 이 순간을 손으로 짠 웨이브 테이블에 박아둔다. 이 게임은 그 순간을 **내 빌드를 읽는 AI가 매번 새로 편성**한다. 같은 게임이 두 번 나오지 않는다.

**선언→실행이 신뢰를 만든다.** AI가 개입하는 게임의 약점은 "정말 AI가 한 건지" 안 보인다는 것. 이 게임의 마왕은 수를 먼저 말하고 그대로 둔다. 선언한 유닛의 실제 웨이브 점유율 평균 47%(후반 61%), 전술 선언 정합 100%, 거짓 선언 0건 — 전부 자동 계측으로 검증했다.

**회귀 기억이 다시 부른다.** 게임은 유저를 다시 불러들여야 한다. 이 게임의 재방문 명목은 보상이 아니라 상대다 — 내 버릇을 기억하고 강해져서 돌아오는 마왕. 이기는 유저에게만 예산 계수가 오르는 군비경쟁 구조라, 고전하는 유저는 조여지지 않는다.

사행성 요소는 없다: 점수·환전·구매·가챠 없음. 마왕의 예산과 상성표는 전부 결정론적 규칙이다.

## 5. 화면·조작

(PDF 변환 시 스크린샷 6종: 타이틀 / 스캔·락온 / 선언 배너 / 전투 / 회귀 인사 / 회귀록)

- 조작: 타워 선택 → 빈 자리 클릭 설치 / 내 타워 클릭 = 강화(Lv5, 비용은 타워 위 ⬆ 배지)
- 종료 조건: 10웨이브 방어 성공(마왕 격퇴) 또는 목숨 소진. 한 판 5~8분, 배속 시 3~4분

## 6. 개발

- 순수 HTML/CSS/JS, 프레임워크 0, 외부 API 0, 에셋 파일 0(사운드 WebAudio 합성), 저장 localStorage
- 1인 개발 (기획 + AI 협업). 제작 과정은 「AI 활용 기술 문서」와 커밋 로그에 공개
- 레포에는 이 게임까지 4개의 게임이 있다 — 3번의 피벗을 전부 플레이 가능한 상태로 남겼다 (README "과정 아카이브")
