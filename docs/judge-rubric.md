## STEP 0 — 평가자 역설계

### 누가 심사하나 (근거 기반 추론)

- 심사 계정이 **dl_gameai_reviewer@nhn.com** — "Game AI" 조직 메일링 리스트. 심사 주체는 NHN의 게임·AI 담당 조직이다 (근거: 사전과제 안내 원문)
- 대회 목적이 채용("최종 면접 직행", "근속 보너스") — 기술 심사자 외에 **채용 결정권자(게임 프로듀서/디렉터급)**가 본다
- 10팀 선발에 지원은 수백 팀 규모 예상(상금 3.5억+채용 혜택) → **1차 스크리닝은 빠르다: 영상 60초 + 링크 클릭 후 첫 1분이 생사를 가른다**
- 슬로건 "AI를 활용하는 사람은 많다. **AI의 다음 단계를 설계할 디렉터**를 찾는다" → 단순 "AI로 만들었어요"는 명시적으로 변별력 없음 선언. 설계력을 본다

### 결정적 해석 포인트 — "AI를 활용한 게임 제작"의 이중 의미

```
해석 A: 제작 과정에 AI (AI 도구로 코딩·아트·사운드)   ← 전원이 이걸 함. 변별력 없음
해석 B: 게임플레이 안에 AI (AI가 없으면 성립하지 않는 게임) ← 심사자가 Game AI 조직. 차별화 지점
```
가설: A는 기본값(감점 방어), B가 득점 지점. 슬로건의 "다음 단계"가 이 방향을 가리킨다.
→ 컨셉 채점(STEP 2)에서 B 여부를 배점에 반영한다.

### 렌즈 1 — 논리 심사자 (Game AI 엔지니어)
맥락 없이 제출물 5종을 기계적으로 대조한다. 링크가 안 열리면 그대로 끝. 커밋 기록을 열어 AI가 한 방에 뱉었는지 과정이 있는지 본다. AI 활용 문서에서 "도구 나열"과 "설계"를 구분한다. 시각적 매력은 판단하지 않는다.

### 렌즈 2 — 취향 심사자 (채용 관점의 게임 디렉터)
바쁘다. 영상 30초 보고 계속 볼지 결정한다. 링크를 직접 눌러 1분 플레이한다. "재밌나? 새로운가?"가 먼저고, 그다음 "이 사람이 48시간 본선에서 뭘 할까, 같이 일하고 싶은가"를 본다. 과장·허세에 알레르기. 완성도(작아도 완결)를 스코프 욕심(크지만 미완)보다 높게 산다.
