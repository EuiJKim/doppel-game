# 가계부

폰 홈 화면에 설치해서 쓰는 간단한 가계부(PWA). 게임과는 별개이고 이 폴더 안에서만 동작한다.

**주소**: https://euijkim.github.io/doppel-game/ledger/ (main 브랜치에 합쳐진 뒤부터 열린다)

## 설치

- **안드로이드(Chrome)**: 주소를 열고 홈 화면의 "설치" 버튼, 또는 브라우저 메뉴(⋮) → 앱 설치
- **아이폰(Safari)**: 주소를 열고 공유 버튼 → 홈 화면에 추가. 설치한 앱과 Safari는 기록을 따로 보관하므로 설치 후에는 앱에서만 기록한다

## 기능

- 지출·수입 기록: 숫자판으로 금액 → 카테고리 → 저장. 날짜는 기본 오늘, 메모는 선택
- 홈: 이번 달 남은 예산, 하루에 쓸 수 있는 돈, 수입·지출 합계, 최근 내역
- 내역: 달력 보기 / 목록 보기, 눌러서 수정·삭제(되돌리기 가능)
- 통계: 카테고리별 합계, 최근 6개월 추이, 지난달 이맘때와 비교
- 고정 내역: 월세·통신비·월급을 한 번 등록하면 매달 그 날 자동 기록
- 카테고리 추가·수정, 백업 파일 내보내기·가져오기(합치기), 밝은/어두운 화면 자동, 오프라인 동작

## 저장

지금은 기록을 **이 기기(localStorage)에만** 저장한다. 여러 기기·가족 동기화는 다음 단계(로그인 + 클라우드 DB)에서 붙인다.
기록마다 `id · updatedAt · deleted`를 갖고 있어서 같은 형태 그대로 합칠 수 있다(`logic.js`의 `mergeRecords`).

## 코드

빌드 없음, 외부 라이브러리 없음.

| 파일 | 내용 |

| `app.js` · `style.css` · `index.html` | 화면 |
| `sw.js` · `manifest.webmanifest` · `icons/` | 설치·오프라인 |
