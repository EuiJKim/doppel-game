# 가계부

폰 홈 화면에 설치해서 쓰는 간단한 가계부(PWA). 게임과는 별개이고 이 폴더 안에서만 동작한다.

**주소**: https://euijkim.github.io/doppel-game/ledger/ (main 브랜치에 합쳐진 뒤부터 열린다)

## 설치

- **안드로이드(Chrome)**: 주소를 열고 홈 화면의 "설치" 버튼, 또는 브라우저 메뉴(⋮) → 앱 설치
- **아이폰(Safari)**: 주소를 열고 공유 버튼 → 홈 화면에 추가. 설치한 앱과 Safari는 기록을 따로 보관하므로 설치 후에는 앱에서만 기록한다

## 기능

- 지출·수입 기록: 숫자판으로 금액 → 카테고리 → 저장. 날짜는 기본 오늘, 메모는 선택. '저장하고 계속'으로 여러 건을 이어 적는다
- 홈: 이번 달 남은 예산, 오늘 남은 돈·오늘 쓴 돈, 수입·지출 합계, 최근 내역
- 내역: 달력 보기 / 목록 보기, 눌러서 수정·삭제(되돌리기 가능). 돋보기로 메모·카테고리·금액·적은 사람을 찾는다(이번 달 또는 전체 기간). 옆으로 밀면 달이 넘어간다
- 통계: 카테고리별 합계(누르면 그 내역), 최근 6개월 추이, 지난달 이맘때와 비교
- 고정 내역: 월세·통신비·월급을 한 번 등록하면 매달 그 날 자동 기록
- 가족과 같이 쓰기: 가족 코드로 여러 기기가 같은 가계부를 본다. 기기마다 이름을 정하면 내역 옆에 누가 적었는지 이름표로 보이고, 입력 창에도 누구 이름으로 적히는지(고칠 때는 누가 적었는지) 나온다. 위쪽 버튼을 누르거나 화면을 아래로 당기면 바로 맞춘다
- 카테고리 추가·수정, 백업 파일 내보내기·가져오기(합치기), 밝은/어두운 화면 자동, 글자 크기 3단계, 오프라인 동작

## 저장과 동기화

기록은 먼저 **이 기기(localStorage)** 에 저장한다. 그래서 인터넷이 없어도 쓸 수 있다.

**가족과 같이 쓰기**(설정 화면): 한 폰에서 가족 코드(20자)를 만들고 다른 폰에서 그 코드를 입력하면 같은 가계부가 된다. 로그인은 없다.

- 코드에서 보관함 주소와 암호 열쇠를 따로 계산한다. 서버(Firestore)에는 AES-GCM 암호문만 올라가서, 코드를 모르면 주소를 알아도 내용을 읽을 수 없다
- 바뀐 기록만 올리고 받는다. 앱을 열 때·다시 볼 때·기록을 적은 직후·보고 있는 동안 30초마다 맞춘다
- 같은 기록을 두 기기가 고쳤으면 늦게 고친 쪽이 이긴다. 삭제는 '지움 표시'로 전달된다
- 코드를 아는 사람은 누구나 보고 고칠 수 있으므로 가족에게만 알려 준다

### 동기화 켜기 (한 번만)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만든다 (Google 애널리틱스는 꺼도 된다)
2. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치는 `asia-northeast3 (서울)`, **프로덕션 모드**
3. 규칙 탭에 [`firestore.rules`](firestore.rules) 내용을 붙여 넣고 게시
4. 프로젝트 설정(톱니바퀴) → 일반의 **프로젝트 ID** 를 [`config.js`](config.js)의 `projectId` 에 적는다

`projectId` 가 비어 있으면 동기화 메뉴는 '준비 중'으로 보이고 앱은 이 기기에만 저장한다.

## 코드

빌드 없음, 외부 라이브러리 없음.

| 파일 | 내용 |
|---|---|
| `logic.js` | 합계·예산·고정 내역·추이 계산 (순수 함수) |
| `store.js` | 이 기기 저장소 |
| `sync.js` · `config.js` · `firestore.rules` | 가족 코드 동기화, 설정, 서버 보안 규칙 |
| `fake-firestore.js` | 테스트용 가짜 서버 (앱에서는 쓰지 않음) |
| `app.js` · `style.css` · `index.html` | 화면 |
| `sw.js` · `manifest.webmanifest` · `icons/` | 설치·오프라인 |

테스트: `node ledger/test.js`
