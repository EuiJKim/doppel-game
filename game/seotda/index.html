특수족보 (설정에서 끌 수 있음) 땡잡이(3띠+7열끗)는 1~9땡을 잡는다 · 암행어사(4열끗+7열끗)는 13·18광땡을 잡는다 · 구사(4+9)는 상대가 알리 이하면 재경기 · 멍텅구리구사(4열끗+9열끗)는 상대가 장땡 이하면 재경기

모드 2장 섯다: 1장 → 베팅 → 1장 → 베팅. 3장 섯다: 2장 → 베팅 → 1장 → 3장 중 2장 선택 → 베팅. 홀덤 섯다: 개인 2장 → 베팅 → 공유 2장 → 베팅 → 공유 1장 → 베팅, 5장 중 최선의 2장. 방장이 판 사이에 언제든 바꿀 수 있다.

베팅 삥(100원)·따당(현재 베팅의 2배)·쿼터(팟의 ¼)·하프(팟의 ½)·콜·체크·다이. 돈이 모자라면 올인이 되고 자기 몫까지만 가져간다. 돈을 다 잃으면 언제든 10,000원으로 다시 참가.

쪼기 내 카드는 뒤집혀 오고, 위로·옆으로·모서리·뒤집기·살살 중 골라서 직접 연다.

연결 같은 와이파이가 아니어도 된다. 방장이 브라우저를 닫으면 방이 사라지니 방장은 끝까지 남아 있자. 게임 중에도 방 코드로 들어올 수 있다 (다음 판부터 참가).
